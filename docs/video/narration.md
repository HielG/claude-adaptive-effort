# Narration

Spoken by Gemini speech generation (`gemini-3.8-flash-tts`, voice Charon,
styled "calm, clear and measured"), one clip per scene, each starting 0.2 s
after its scene does. Generated by `tts.js`, mixed by `mix.sh`.

| Start | Scene | Line |
| --- | --- | --- |
| 0:00 | Title | Adaptive effort: reasoning effort that follows the work. |
| 0:05 | One level for every turn | Most sessions run every turn at one effort level. Small talk overpays, and hard turns underthink. |
| 0:12 | Read the prompt | It reads each prompt. Thanks drops to low. Work keeps your level. A review jumps to max. A quick yes keeps the last one. |
| 0:23 | Where it hooks in | One hook classifies the prompt. Another sets the effort on every request in that turn, then reads back the cost. |
| 0:31 | The catch: the prompt cache | There's a catch. Re-reading cached context is cheap, but if changing effort rewrites that cache, a cheap turn can cost far more than it saves. So every dip is priced first. |
| 0:44 | It measures, then learns | After a switch, it checks what the cache still served. On Opus 5.5, nearly all of it, so dips are free. |
| 0:52 | The ledger | Run slash adaptive effort to see what it saved. Measured, not guessed. |

Music: synthesized locally by `music.js` (slow pads over Am - F - C - G with
sparse bell notes), about 20 dB under the voice and ducked while it speaks.

To rebuild: `node music.js && node tts.js && bash mix.sh` (`tts.js` needs
`GEMINI_API_KEY`; the free tier allows 3 clips a minute, so run
`LINES=1,2,3 node tts.js` and so on in batches).
